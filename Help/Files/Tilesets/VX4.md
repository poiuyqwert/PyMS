# VX4
`.vx4` files define the graphics of each MegaTile in a [Tileset](/Help/Files/Tilesets/Tilesets.md), as a 4x4 grid of references to MiniTile graphics in the [.vr4](/Help/Files/Tilesets/VR4.md) file, each with a flag to horizontally flip the MiniTile.

Edited by [PyTILE](/Help/Programs/PyTILE.md)
