# VR4
`.vr4` files contain the 8x8 pixel graphics of each MiniTile in a [Tileset](/Help/Files/Tilesets/Tilesets.md), with each pixel being an index into the tileset's [.wpe](/Help/Files/Palettes.md#terrain-wpe) palette. MiniTiles are combined into MegaTiles by the [.vx4](/Help/Files/Tilesets/VX4.md) file.

Edited by [PyTILE](/Help/Programs/PyTILE.md)
