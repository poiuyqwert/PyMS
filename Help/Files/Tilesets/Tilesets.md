# Tilesets
Tilesets are made up of a bunch of files, the main files are:
- [.cv5](/Help/Files/Tilesets/CV5.md): The main file, contains Tile Groups
- [.vx4](/Help/Files/Tilesets/VX4.md): Defines each MegaTile as a 4x4 grid of MiniTile graphic references (an expanded `.vx4ex` variant raises the MiniTile limit)
- [.vr4](/Help/Files/Tilesets/VR4.md): The 8x8 pixel graphics of each MiniTile
- [.vf4](/Help/Files/Tilesets/VF4.md): The per-MiniTile flags (walkability, height, etc.) of each MegaTile
- [dddata.bin](/Help/Files/Tilesets/dddata.bin.md): Placement data for the tilesets Doodads
- [.wpe](/Help/Files/Palettes.md#terrain-wpe): The palette for the tileset
